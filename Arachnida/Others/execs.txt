spider
    uso básico sin recursividad
        /usr/bin/python3 spider.py https://ejemplo.com
    Con recursividad (flags opcionales)
        /usr/bin/python3 spider.py -r -l 3 -p ./mis_imagenes https://ejemplo.com
    Por ejemplo, para descargar imágenes de una web con recursividad hasta profundidad 2
        /usr/bin/python3 spider.py -r -l 2 -p ./descargas https://ejemplo.com   
    otros a data (sencilla)
        /usr/bin/python3 spider.py -r -l 1 https://books.toscrape.com
    otros a otra carpeta    
        /usr/bin/python3 spider.py -r -l 1 -p ./myfolder https://books.toscrape.com

    breve
        /usr/bin/python3 spider.py https://books.toscrape.com/catalogue/category/books/science_22/index.html
        /usr/bin/python3 spider.py -r -l 1 https://books.toscrape.com/catalogue/category/books/science_22/index.html

    para la defensa

        1. Caso básico (sin recursividad, path por defecto ./data)
            /usr/bin/python3 spider.py https://books.toscrape.com/catalogue/category/books/science_22/index.html
        2. Caso recursivo con límite de profundidad
            /usr/bin/python3 spider.py -r -l 1 https://books.toscrape.com/catalogue/category/books/science_22/index.html
        3. Caso con path personalizado
            /usr/bin/python3 spider.py -p ./my_test_data https://books.toscrape.com/catalogue/category/books/science_22/index.html

        Ejecutas el 1.
            ls data | wc -l
        Ejecutas el 2.
            ls data | wc -l
        Ejecutas el 3.
            ls my_test_data | wc -l
